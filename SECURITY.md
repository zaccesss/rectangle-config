# Security Policy

## Scope

This repository is a single Rectangle config file and setup instructions. It contains no service and no library. In scope:

- Config that does something other than what the guides document
- Setup instructions that would leave insecure file permissions behind
- A setup instruction that would leave insecure file permissions behind

## Out of scope

- A vulnerability in Rectangle itself, report that upstream

## Reporting a vulnerability

> [!IMPORTANT]
> Report privately, not in a public issue. Email contact@isaacadjei.me with details and
> reproduction steps. Expect an acknowledgement within a few days.
